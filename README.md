# Madhav Suryawanshi — Portfolio

Static HTML/CSS/JavaScript portfolio designed for GitHub Pages.

## Files

- `index.html` — portfolio content
- `style.css` — responsive styling and animations
- `script.js` — scroll reveals, navbar, cursor glow and mobile menu
- `assets/profile.jpg` — profile photo
- `MadhavSuryawanshi_Resume.pdf` — resume

## GitHub Pages

1. Create/use the repository `Madhav_Portfolio`.
2. Upload all files so `index.html` is in the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select **main** and **/(root)**.
6. Save and wait for deployment.

The website URL should be:

`https://madhav9353.github.io/Madhav_Portfolio/`
